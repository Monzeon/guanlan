# PDF 正文抽取 · 版面还原

> 改动文件：`pdf_text.py`（新增）、`server.py`、`reading.py`、`README.md`、
> `tools/verify_pdf_parse.py`、`tools/rollback_pdf_layout.py`。
> 逐行差分见 [`PDF-正文抽取.patch`](PDF-正文抽取.patch)。

## 一、问题

《独立宣言》中英对照（Skia/Chrome 生成，6 页，242 KB）导入后，「正文」面板是这样：

```
EN In Congress, July 4, 1776.中大陆会议， 1776 年 7 月 4 日。
EN The unanimous Declaration of the thirteen united States of America.中美利坚合众国十三州一致通过的《独立宣言》。
EN When in the Course of human events, … which have connected them with another, …
    requires that they should declare the causes which impel them to the separation.中在人类事务发展的过程中…
```

三件事同时坏了：

1. **原文和译文粘成一句**，中间连空格都没有（`1776.中大陆会议`）；
2. **一个自然段被从中间锯开**：`…of mankind` 一段、`requires that they should…` 又一段，切开的位置正好是「字数到了」的位置；
3. **段落边界全丢**：12,297 字的正文只切出 46 段，而实际是 30 组中英对照。

同类问题在别的 PDF 上还会变形：双栏论文左右串栏、页眉和页码每页插一句、段首缩进被抹平、
行末断词留着连字符。

## 二、根因

问题不在 pypdf 读不出字，而在**读出来的字没有版面**：

| 层 | 现象 | 原因 |
|---|---|---|
| 抽取 | 行列关系丢失 | `page.extract_text()` 按内容流顺序吐字，同一基线上的先后只反映写入顺序，不反映视觉位置 |
| 分段 | 按字数硬切 | `normalize_body_text()` 的 `flush_if_sentence()`：累计 ≥260 字就断，不看句末标点、不看缩进 |
| 接行 | 中英边界不补空格 | `_smart_join()` 只在「ASCII 字母/数字」边界补空格，`1776.` + `中大陆会议` 直接相撞 |
| 去空格 | 连标签一起删 | 中文逐字拆分修复用的正则会把「中 大陆会议」的空格一并删除 |

第三、四条是独立的 bug，即使 PDF 抽得再好也会把双语对照毁掉，所以这轮一起修。

## 三、做法：先还原版面，再切段

新增 `pdf_text.py`，只用随应用携带的 `vendor/pypdf`，不新增依赖。五步：

| 步骤 | 做法 | 关键判据 |
|---|---|---|
| 1. 取字 | `page.extract_text(visitor_text=…)` 逐个文字块拿 `(x, y, 字号)`，`tm × cm` 求设备坐标，按基线聚成行 | 同一行的容差 `0.42 × 正文字号`；竖排/旋转文字整页退回内容流顺序 |
| 2. 分栏 | 行内出现 > 2em 的空隙就切成「单元」；整页 ≥30% 的行有两个等宽单元、且断点集中在同一条竖线，判为双栏 | 栏缝两侧都不能有字横跨；双栏按「通栏 → 左栏到底 → 右栏到底」重排，每栏各自成流 |
| 3. 去页眉页脚 | 页面上/下 10% 内、跨页重复（数字归一后比对，≥50% 页出现）或纯页码的行，整行丢掉 | `- 12 -`、`第 3 页`、`Page 2 of 9`、`3 / 9` 都认 |
| 4. 切段 | 行距 > 1.42 倍基准行距、字号变化 >16%、首行缩进、双语标签切换、上一行明显短于本段右界、居中标题接正文、列表项另起 | 「短行」以**本段自己的右界**为准，不拿整页右界——中英文栏宽本来就不同 |
| 5. 接行 | 段内把行接回长句：中文之间不补空格，英文补一个空格，行末 `hyphen-` 还原成 `hyphenated` | 网址里的连字符不还原（`declaration-of-independence` 不能被接成 `declarationof-independence`） |

双语对照单独处理：行首是「短标签 + 字号比正文小」的形态（`EN`、`中`、`译文`…）才认作标签，
标签一换就另起一段，所以每一组原文/译文都是独立段落，`bodyBlocks()` 按空行切开后
在阅读器里就是干净的两段。

版面不像「成篇正文」的页面（海报、公众号长图、封面：一行只有一两个字，或最大字号超过正文字号 2.4 倍）
整页退回 pypdf 的内容流顺序——那是排版软件写入的阅读顺序，比按坐标猜更稳。

## 四、效果

同一份《独立宣言》，改前 / 改后：

```
改前  EN In Congress, July 4, 1776.中大陆会议， 1776 年 7 月 4 日。
改后  EN In Congress, July 4, 1776.
      中 大陆会议，1776 年 7 月 4 日。
```

段落数从 46 段变成 75 段（30 组对照 + 标题 + 署名 + 来源），「1776.中大陆会议」这类粘连 0 处。

本机 8 个真实 PDF 的前后对比（`tools/verify_pdf_parse.py --pdf` 可复现覆盖率的算法）：

| 文件 | 改前字数 | 改后字数 | 字面覆盖率 | 用时 |
|---|---:|---:|---:|---:|
| WSJ 中国经济（印刷网页） | 6,862 | 6,165 | 100% | 0.3s |
| 视频整理 E269（32 页） | 25,516 | 26,162 | 100% | 4.9s |
| 1968 逐字稿 | 10,939 | 10,923 | 100% | 1.1s |
| 世界苦茶切片 | 8,496 | 8,634 | 100% | 1.1s |
| 结构化简报 | 16,902 | 17,512 | 99% | 1.7s |
| 证据核查报告 | 8,800 | 9,012 | 98% | 0.4s |
| 视频情报报告 | 11,735 | 12,253 | 98% | 0.5s |
| 独立宣言中英对照 | 12,326 | 12,349 | 100% | 0.2s |

字数下降的是页眉页脚与页码被删掉的那部分；覆盖率按二元组抽样对照 pypdf 裸抽取，
98% 以下是页眉页脚被有意删掉的份额，不是掉字。抽取耗时基本不变（visitor 与裸抽取共用一次解析）。

`python tools/verify_pdf_parse.py` 现造 7 份最小样张，逐条验收：

```
✓ 中文单栏：标题独立成段        ✓ 英文断词：hyphen- + ated 合回 hyphenated
✓ 中文单栏：两段分开            ✓ 英文断词：wrap- + ping 合回 wrapping
✓ 中文单栏：汉字之间不留空格    ✓ 英文缩进：四空格缩进另起一段
✓ 双栏：左栏读完再读右栏        ✓ 双栏：页眉与页码不进正文
✓ 双语：EN 与译文各成一段       ✓ 双语：原文末句不粘译文
✓ 扫描件：明确说没有文字层      ✓ 加密件：明确要密码
✓ 页首长正文不被当成页眉删掉
13/13 通过
```

## 五、边界

- **扫描件、图片版**：没有文字层就是没有，报「PDF 里没有可读取的文字层，可能是扫描件或图片版」，
  不伪造解析成功；要读内容得先 OCR。
- **加密件**：只尝试空密码，不猜用户密码，报「PDF 已加密，需要密码才能读取」。
- **文字层编码坏了**（私用区字符成片、替换符）：先退回 pypdf 裸抽取再看，仍不行就报「文字层编码异常」。
- **竖排、旋转页**：整页退回内容流顺序，不按坐标猜。
- **上限**：最多 200 页、6 万字，与改动前一致。

## 六、生效与回滚

- 新导入的 PDF 自动走新链路；**老条目**要到详情页点一次「重提正文」，
  或调一次 `POST /api/tools/backfill {"redo":"pdf"}` 批量重抽所有 PDF（批注按原句重新锚定，不会丢）。
- 回滚：`python tools/rollback_pdf_layout.py --apply`（先 `--dry-run` 预览）；
  `server.py`、`reading.py` 会退回 `*.bak-20261109-pdf`，`pdf_text.py` 与本文档一并删除。
