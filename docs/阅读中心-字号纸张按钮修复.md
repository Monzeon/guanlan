# 阅读中心 · A− / A＋ / ◐ 按钮修复

记录时间：2026-11-09
影响范围：`#/reading/book/:id` 阅读器页头工具栏

## 一、现象

阅读器页头中间的「A−（缩小字号）」「A＋（放大字号）」「◐（切换纸张）」三枚按钮，点击后正文没有变化，纸张也不换，看起来像没绑事件。

## 二、根因：重复 id 把样式写到了按钮上

`static/reading.js` 的 `renderBookShell()` 里，工具栏按钮与正文纸面容器**共用了同一个 id**：

| 原行号 | 代码 |
| --- | --- |
| 640 | `<button type="button" class="rc-icon-btn" id="rc-paper" title="切换纸张">◐</button>` |
| 649 | `<div class="rc-paper" id="rc-paper" data-paper="…" style="--rc-fs:…">` |

`$` 的定义在 `static/app.js:36`：`const $ = (s, r = document) => r.querySelector(s);`
—— 只返回 DOM 中**第一个**匹配，也就是位置靠前的那枚按钮。

于是 `bindBook()` 里的 `applyType()` 实际执行成：

```js
const paper = $("#rc-paper");            // 拿到的是按钮，不是纸面
paper.style.setProperty("--rc-fs", …);   // 变量写在按钮上
paper.style.setProperty("--rc-lh", …);
paper.style.setProperty("--rc-w", …);
paper.dataset.paper = P.paper;           // data-paper 也写在按钮上
```

而 `static/reading.css:366–385` 的规则全部挂在纸面容器及其后代上：

```css
.rc-paper { width: min(100%, calc(var(--rc-w) + 92px)); … }
.rc-paper[data-paper="sepia"] { background: #f6efdf; … }
.rc-article { font-size: var(--rc-fs); line-height: var(--rc-lh); … }
```

按钮不在这条继承链里，纸面 div 上的内联变量始终是首次渲染时写死的那一组值 →
字号、行距、宽度、纸张四项全部原地不动。三枚按钮共用同一个 `applyType()`，所以一起失效。
另外 `$("#rc-paper").addEventListener("click", …)` 绑到的也是按钮；纸面 div 自始至终没拿到监听。

## 三、改动清单

| 文件 | 改动 |
| --- | --- |
| `static/reading.js` | 按钮 id → `rc-paper-btn`；纸面 div id → `rc-paper-surface`；`applyType()` 改取 `#rc-paper-surface`；纸张点击改绑 `#rc-paper-btn` |
| `android-local/app/src/main/python/static/reading.js` | 同一份修复同步到 Android 内嵌静态资源，避免桌面修好、移动端仍旧 |
| `static/reading.js.bak-20261109-toolbar` | 改前原文件备份 |
| `android-local/.../reading.js.bak-20261109-toolbar` | 改前原文件备份 |

两份文件的变更集经逐行比对完全一致（各 37 行增删），`node --check` 均通过，源码内已无残留 `#rc-paper` 引用。

### 顺手补上的可见反馈

1. 三枚按钮的 `title` / `aria-label` 动态显示当前字号与纸张名（例如「放大字号（当前 18px）」「切换纸张（当前：牛皮纸）」）。
2. 字号到 13px / 26px 边界时给一行 toast，连点到底也有回应。
3. 切换纸张后 toast 报出当前纸张。浅色主题下「夜间纸」按既有设计回落到白纸底色，视觉差异弱，文字反馈把状态变化交代清楚。
4. `bindBook()` 末尾调用一次 `applyType()`，让 `localStorage` 恢复的偏好同步到纸面与按钮标题。

原先纸张切换同时调整行距与宽度的逻辑保持原样，未改行为。
