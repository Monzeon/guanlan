> 改动文件：`reading.py`、`static/reading.js`、`static/reading.css`、`README.md`。
> 逐行差分见 [`阅读中心-解析与排版.patch`](阅读中心-解析与排版.patch)，截图在 [`shots-parse/`](shots-parse/)。

## 一、问题

导入《孤独社会》后，目录是 **70 条平铺的「章」**：里面混着真正的章节、章节内的小节（"相处34年的房东"这类）、书的版权页/目录页，还有一条来源不明的「第 4 节」。打开第一章，正文第一行又是「第一章 夏日异常天气……」，和页首标题重复；小节标题和正文一个字号，读者分不出层次。繁体那本《叛離、抗議與忠誠》同样有两条 `第 2 节 / 第 4 节 / 第 7 节`，还漏了「附錄 C」。

根因在 EPUB 解析：

1. **按 spine 文件切章，而不是按目录切章**。Calibre 类 EPUB 会把一章拆成 `split_000…009`，只有 `split_000` 在目录里，其余没有标题，只好用「第 N 节」兜底；
2. **目录层级被拍平**，`附錄 > 附錄 A…E` 的父子关系丢了；同一文件里的多个目录项（附錄 C/D 同在 `BK7080-19.xhtml`）后一个把前一个覆盖掉，附錄 C 直接消失；
3. **标题当成正文**：EPUB 的 `<h1>/<h2>` 被转成普通文字，既没有从正文里去掉，也没有排成标题；
4. 正文按 `<p>` 分得没错，但排版是网页式的：段间大空白、首行不缩进，和「书」的阅读习惯不符。

## 二、解析：按目录锚点切章，按标题分节

`reading.py` 的 EPUB 解析重写为四步：

| 步骤 | 做法 |
|---|---|
| 读目录 | EPUB3 `nav[epub:type=toc]` 或 EPUB2 `ncx`，**保留层级**（`<ol>` 嵌套 / `<navPoint>` 嵌套），条目记 `(文件, 锚点, 标题, 层级)` |
| 定位 | 解析每个 XHTML 时同时登记 `id → 正文字符偏移`，目录锚点因此能落在**段落级**位置，而不是整份文件 |
| 切章 | 一个 spine 文件里有几个目录锚点就切几段（附錄 C/D 分开）；没有目录锚点的分片（`split_001…`）**并回上一章**；父级只有标题没有正文时（如「附錄」总标题），子项整体升一级 |
| 分节 | 章内 `h2/h3…` 记为小节：标题文字留在正文里原位（连续阅读），另存 `sections: [{title, level, offset}]` 供目录使用；开头与章名重复的标题行去掉 |

配套的小修：

- `<h1>` 里的 `<br>` 归成空格（原来会粘成「第一章夏日异常天气」）；
- 目录标题优先于文件里的 `<title>`；封面/题献页的 `<title>` 若是文件名（`BK7080`），章名记为「开篇」；
- 整本书没有目录时，回退到按 `h1`（无 `h1` 则 `h2`）切章，`h2/h3` 仍作小节；
- 图片页保留目录项，正文给一行「〔本節為圖版，暫未提取圖像〕」，不再整节消失；
- 章节先合并再截断，`MAX_DOC_CHARS` 上限不变。

数据形状（`chapters` JSON）只多了一个可选的 `sections` 字段，老数据、老接口、导出、FTS 都不受影响：

```json
{ "id": "ch5", "title": "第一章 夏日异常天气引发特殊清扫行业小型泡沫",
  "level": 1, "start": 3257, "end": 17881, "chars": 14624,
  "sections": [ { "title": "大量灌满尿液的塑料瓶", "level": 2, "offset": 0 } ] }
```

## 三、排版：目录树、小节标题、书籍版式

- **目录**：章一行；有子节的章前面多一个 `▸/▾`，点开才列出小节（当前章默认展开，其余收起）。点小节直接跳到该段（`jumpTo` 用绝对字符偏移），并在目录里高亮。
- **章头**：小标题行从「第 5 / 70 章」变成真实章数，并带上「· 10 节」。
- **正文**：小节标题按 `<h3 class="rc-sec">` 排版（衬线加粗、上下留白），不再是普通段落；书类资料的段落**首行缩进两字**、段间距收紧到 0.55em，接近纸书；文档/网页类保持原来的网页式排版。
- **定位**：续读和跳转的落点统一走 `revealTop()`——离章首太近时直接回到章头，避免把标题切掉半行。
- **重新解析**：目录栏底部新增入口，按原件重建目录与正文；进度按百分比折算，批注按原句重新锚定。`POST /api/reading/items/{cid}/reparse`。

## 四、两本书的实际变化

| 书 | 改前 | 改后 |
|---|---|---|
| 孤独社会 | 70 章平铺，含「第 4 节」；正文重复章名；小节当章名 | **10 章 / 63 节**（书名页·版权页·前言·目录·第一至五章·终章），小节归位到各章之下 |
| 叛離、抗議與忠誠 | 21 章，含「第 2 节 / 第 4 节 / 第 7 节」，缺附錄 C | **20 章 / 17 节**，三个占位章并回上一章，附錄 A–E 齐全 |

## 六、回滚

```bash
python tools/rollback_parse_layout.py --dry-run     # 预览
python tools/rollback_parse_layout.py --apply       # 还原 reading.py / reading.js / reading.css / README 那一行
python launch.py --stop && python launch.py         # 重启生效
```

回滚只还原代码，不回滚已经重解析过的书（正文与目录仍在库里，旧前端也能正常读）。若要回到旧目录，重新导入原件即可。
