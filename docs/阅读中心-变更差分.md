## 一、新增文件

| 文件 | 作用 |
|---|---|
| `reading_schema.sql` | 7 张表 + 1 个 FTS5 虚表 + 索引（`CREATE TABLE IF NOT EXISTS`，老库原地升级） |
| `reading.py` | 阅读中心服务端模块：结构化解析、FTS 检索、25 个 API、归档、AI 伴读 |
| `static/reading.js` | 7 个视图 + 阅读器交互（选区/高亮/书签/目录/进度/笔记/关联/AI） |
| `static/reading.css` | 板块切换器、宽版书架、整屏三栏阅读器、第五色、响应式 |
| `docs/阅读中心-设计与实现.md` | 完整功能设计与落地实现步骤 |
| `tools/rollback_reading_center.py` | 回滚脚本（默认 dry-run） |

## 三、未改动

- `schema.sql`：主库 Schema 与阅读扩展解耦，新表单独放 `reading_schema.sql`。
- `style.css` / `extra.css` / `mobile.css`：完全复用原设计系统变量，新增样式只在 `reading.css`。
- 所有原有 API、原有表、用户既有数据：无破坏性变更；`reading_items` 对 `clips` 是 1:1 扩展，删阅读态不动原件。

## 四、数据层变更（`init_db()` 自动执行）

```
+ reading_items        (clip_id PK/FK, kind, format, shelf_id, doc_text, chapters,
                        status, progress, position, position_unit, read_seconds, meta)
+ reading_shelves      (name, parent_id, board_id, sort)
+ reading_bookmarks    (offset, time_sec, chapter_id, label)
+ reading_notes        (content_md, source_quote, source_annotation_id, kind, archived_clip_id)
+ reading_links        (src_kind/id, dst_kind/id, relation, clip_id)  UNIQUE
+ reading_sessions     (day, clip_id, seconds, chars) UNIQUE(day, clip_id)
+ reading_fts          FTS5(kind, clip_id, ref_id, offset, title, body) tokenize=trigram
```

## 五、回滚

```bash
python tools/rollback_reading_center.py --dry-run                  # 预览
python tools/rollback_reading_center.py --apply                    # 还原文件
python tools/rollback_reading_center.py --apply --drop-data        # 连阅读数据一起清
python launch.py --stop && python launch.py                        # 重启生效
```

脚本按**精确片段**逆变换，不会用 `git checkout` 覆盖你更早的未提交修改；`--drop-data` 需显式指定才会 DROP 表。
