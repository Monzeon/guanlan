# 观澜 · 界面重设计提案 v2「案头」

> 只出方案，不动代码。目标：在不改变任何现有功能、路由、数据与交互逻辑的前提下，
> 把界面从"信息齐全的工具"提升为"有编辑气质的工作台"。
>
> 现状代码基线：`static/style.css`（660 行）· `extra.css`（~1750 行）· `reading.css`（608 行）
> · `bible.css`（646 行）· `mobile.css`（11 KB）· `app.js`（4710 行）。

---

## 一、诊断：现在为什么不"高级"

高级感不是装饰堆出来的，是**秩序**堆出来的。现在的问题都能落到具体规则上：

| # | 现象 | 证据 | 后果 |
| --- | --- | --- | --- |
| 1 | 三套视觉各自为政 | `bible.css` 用照片背景 + 五色高亮（`bible-bg.jpg` 164 KB），`reading.css` 是另一套三栏，`extra.css` 又补一套 | 切板块像换了三个 App，品牌没有统一约束 |
| 2 | 权重平均，没有主次 | `.panel` / `.clip-card` / `.stat` 全是 1px 边框 + 12px 圆角 + 同一层阴影 | 眼睛找不到第一落点，满屏"同等重要" |
| 3 | 容器套容器 | `.panel > .panel-body > .clip-card` 三层底色/描边 | 信息被切碎，页面显得吵 |
| 4 | 强调色通胀 | 琥珀同时用于主按钮、链接、选中态、数字、hover 底、chip、进度条（`--accent` 出现 30+ 处） | 强调不再强调 |
| 5 | 字体节奏碎 | 正文 13.5px；元信息大量用等宽且夹中文（`.head .meta` 注释里自己也写了"别用等宽"） | 中文落在等宽里，字面不齐，观感廉价 |
| 6 | 图标系统不统一 | 侧栏 1.6px 线性、移动端另一套、正文里 `▣`／emoji 混排 | 细节处露怯 |
| 7 | 版式没有网格 | 页面 padding 30/40、面板 18、行 11/18、卡片 14/16 混用 | 纵向节奏不稳，长页面越看越散 |
| 8 | 动效靠位移 | `.stat:hover{translateY(-2px)}`、`.clip-card:hover{translateY(-2px)}` | 这是"模板感"的典型信号 |
| 9 | 导航层级混淆 | 板块切换（`.sect-switch` 三个按钮）塞在导航列表里，和 `.nav-item` 同权重 | 一级/二级/三级信息架构看不清 |
| 10 | 深色模式边界靠线撑 | `--bg #0b0e13` 与 `--panel #10141a` 只差 5 个亮度 | 深色下卡片糊成一片 |

## 二、方向：把"纸墨仪器"推进到"案头"

一句话：**一块安静的书桌，纸是底，字是主角，铜是记号笔。**

三条原则（后面所有取舍都从这里来）：

1. **少一层容器，多一层留白。** 能用分隔线和间距解决的，不用边框和卡片。
2. **一屏只允许一个"重音"。** 铜色只出现在"当前动作/当前选中/关键数字"，其余一律墨阶。
3. **文字本身是装饰。** 靠字号、字重、行高、字距建立层级，不靠色块和阴影。

保留现有品牌资产：`观澜` 的衬线字标、波浪标记、纸底、孟子那句副题。它们是对的，只是被稀释了。

## 三、设计语言

### 3.1 色彩（一套中性 + 一支铜 + 四个语义）

```css
/* 浅色 */
--paper:       #F7F5F0;   /* 页面底 */
--surface:     #FFFFFF;   /* 内容面（卡片/浮层） */
--sunken:      #EFEBE2;   /* 凹陷：输入框底、代码块、进度槽 */
--hairline:    #E4DFD3;   /* 0.5–1px 分隔线 */
--hairline-2:  #D2CBBA;   /* 需要强调的边界 */
--ink:         #16181C;   /* 主文字 */
--ink-2:       #4B5058;   /* 次级文字 */
--ink-3:       #8A8F98;   /* 提示、占位 */

--brass:       #96682C;   /* 唯一强调色：更深、更灰的铜，不是橙 */
--brass-hi:    #B07E3A;
--brass-tint:  rgba(150,104,44,.075);

/* 语义（只在有语义时出现，不做装饰） */
--ok:   #3F6B4F;   /* 权威/已收/接通 */
--warn: #9A6A21;   /* 待判/将过期 */
--bad:  #A6482F;   /* 矛盾/失败（砖红，不用正红） */
--info: #45607A;   /* 参考级/链接态 */
```

深色不是把浅色反相，而是重新配一组"夜读"的墨：

```css
[data-theme="dark"] {
  --paper: #0E1013;  --surface: #16191E;  --sunken: #0A0C0F;
  --hairline: #242A32;  --hairline-2: #333B45;
  --ink: #E6E2D8;  --ink-2: #A3A9B2;  --ink-3: #6C727C;
  --brass: #C9A063;  --brass-hi: #DCB77C;  --brass-tint: rgba(201,160,99,.10);
}
```

**用量纪律**：一屏内铜色出现不超过 3 处（一个主按钮、一个选中态、一组关键数字）。
`--ok/--warn/--bad/--info` 只用于状态点、左侧 2px 竖条、极浅底（≤8% 透明度）。

材料级 T0–T4 与圣经五色高亮保留，但饱和度统一降一档，色相不动——这样"分级"仍然一眼可辨，又不会花。

### 3.2 字体与字号阶梯

不再让等宽字体碰中文。等宽只负责 ID、时间、纯数字。

| 角色 | 字体 | 字号 / 行高 | 字重 | 字距 | 用在哪 |
| --- | --- | --- | --- | --- | --- |
| Display | 衬线 | 30 / 40 | 600 | .02em | 板块首页大标题（一屏一次） |
| H1 | 衬线 | 24 / 34 | 600 | .01em | 页面标题（现 `.head h1` 23px） |
| H2 | 衬线 | 18 / 28 | 600 | .01em | 区块标题（现 `.section-head h2`） |
| H3 | 黑体 | 15 / 24 | 600 | 0 | 卡片标题、面板标题 |
| Body | 黑体 | 15 / 26 | 400 | .005em | 正文、详情、AI 输出 |
| Body-S | 黑体 | 13.5 / 23 | 400 | 0 | 列表摘要、次要段落 |
| Meta | 黑体 | 12 / 18 | 400 | .01em | 来源、时间、计数说明 |
| Label | 黑体 | 11 / 16 | 500 | .08em | 分组标题（中文不再大写化） |
| Mono | 等宽 | 12 / 18 | 400 | 0 | `C-2026-0008`、`3,589`、时间戳 |

规则：

- 中文标题一律衬线，**只在 h1/h2/Display 层**；h3 以下回黑体，避免"满屏宋体"。
- 数字统一 `font-variant-numeric: tabular-nums`，列表里宽度不跳。
- 正文最大行宽 **68ch**（约 640px @15px）；详情页正文列固定这个宽度，两侧留白承担"高级"。
- 不再出现 9.5px / 10px 这类字号（可读性下限 11px，正文 15px 起）。

### 3.3 间距、栅格、尺寸

- 基准 **8pt**，只用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 页面：桌面 `32px 48px 96px`（现 30/40）；平板 `24px 32px`；手机 `16px 16px 72px`。
- 区块间距 32；卡片间距 16；卡片内边距 20；列表行 `14px 20px`（双行 88px 高）。
- 内容最大宽 **1200px**；阅读正文列 **68ch**；右栏 inspector **340px**。
- 触控目标最小 44×44（手机）。

### 3.4 圆角、描边、投影

| 元素 | 圆角 | 描边 | 投影 |
| --- | --- | --- | --- |
| 卡片 / 面板 | 10 | `1px solid var(--hairline)` | **无** |
| 输入框 | 8 | `1px var(--hairline-2)` | 无，聚焦时 3px `--brass-tint` 光圈 |
| 按钮 | 8 | 主按钮无描边 | 无 |
| 浮层（弹窗/命令面板/悬浮提示） | 14 | 1px hairline | 唯一允许：`0 12px 32px -16px rgba(20,22,26,.28)` |
| Chip | 999（胶囊） | 1px hairline-2 | 无 |

**卡片不再有阴影**。层次由"纸 vs 面 vs 凹陷"三档底色 + 发丝线建立，这是印刷品的逻辑，也是"高级"的来源。

### 3.5 动效

- 时长：微交互 120ms，常规 200ms，页面切换 280ms；曲线统一 `cubic-bezier(.2,.7,.3,1)`。
- 只动 `opacity` 与 `transform: translateY(4px)`；**取消所有 hover 位移**，改为底色/描边变化。
- 列表进场沿用 `.stagger`，间隔从 26ms 降到 18ms（更快、更克制）。
- 删除 `--ease-spring`（回弹是廉价感的来源之一）；保留 `prefers-reduced-motion` 兜底。

### 3.6 图标

- 统一 20×20，`stroke-width: 1.5`，`stroke-linecap: round`，24 网格。
- 两态：线性（默认）、选中时同路径加深 + 左侧 2px 铜条，不做填充变形。
- 移除正文里的 `▣`、`＋` 等字符图标，改 SVG；文字按钮保留"＋ 新建"这类语义前缀。
- 侧栏、移动端底栏、空态插图共用同一套。

## 四、布局重构（本次重点）

### 4.1 全局壳层：从"两栏"到"三级"

现在是 `224px 侧栏 + 内容`，一级板块、二级导航、三级筛选项全挤在一个 224 的列里。
改成经典的"轨道 + 语境栏 + 工作区"：

```
┌────┬──────────────┬───────────────────────────────────────────────┐
│ 64 │   248        │  56 工具条：面包屑 · 搜索 · 主操作             │
│    │              ├───────────────────────────────────────────────┤
│ 收 │  收存         │                                               │
│ 阅 │  ├ 全部  22   │   页面标题 + 一句副题                          │
│ 圣 │  ├ 资料库 3   │   ─────────────────────────────────           │
│    │  ├ 人口普查 6 │                                               │
│    │  ├ ＋新建板块 │   工作区（列表 / 阅读 / 表单）                 │
│    │              │                                               │
│ ⚙  │  工具         │                                               │
└────┴──────────────┴───────────────────────────────────────────────┘
  轨道    语境栏                 工作区
```

- **轨道（64px）**：三个板块图标 + 底部设置/主题。选中态 = 左侧 2px 铜条 + 图标转深。
  这解决了诊断 #9：板块是"切换场景"，不是"导航条目"。
- **语境栏（248px，可折叠 `⌘\`）**：当前板块的二级结构（板块列表、书架、书卷、筛选）。
  折叠后图标化，给阅读/写作让出宽度；折叠状态存 `localStorage`。
- **工具条（56px，sticky）**：左面包屑（`收存 / 人口普查`），中搜索框（点击唤起 `Ctrl+K` 命令面板），
  右主操作（收存 → 「＋ 收存」；阅读 → 「导入」；圣经 → 「继续读」）。
- **工作区**：`max-width: 1200px`，左对齐；详情页多一个 340px 右栏（可收起）。

移动端（≤860）：轨道与语境栏收进抽屉，底部 5 项 tab（收存/阅读/圣经/问/更多），工具条只留标题 + 一个动作。

### 4.2 收存首页

```
全部收存                                    22 条 · 存下来的东西，AI 只读这里
──────────────────────────────────────────────────────────────────────
 22        15         9          2
 收存      命题       板块       待重看
──────────────────────────────────────────────────────────────────────
┌────────────────────────────────────────────────────────────────────┐
│ 粘贴链接、正文或想法……                            材料级 ▾   ＋收存 │  ← 单行 composer
└────────────────────────────────────────────────────────────────────┘
全部 22   材料 12   资讯 6   未定 4                    [标签 ▾] [筛选]
┌───────────────────────────────┬───────────────────────────────┐
│ 第七次人口普查数据公报（第三号）│ 户籍制度改革与流动人口……       │
│ 国家统计局 · 2021-05-11        │ 财新 · 2021-04-28             │
│ 三行摘要，最多三行，超出省略……  │ 三行摘要，最多三行，超出省略……  │
│ 权威 · T0 · 6 条笔记    ⋯      │ 参考 · T1 · 2 条笔记    ⋯      │
└───────────────────────────────┴───────────────────────────────┘
```

要点：

- **统计条**：从 4 张卡（`.stat`）改成一行"数字 + 标签"，用竖发丝线分隔。省掉 4 个边框，视觉立刻安静。
- **composer**：从常驻大 `textarea`（`.cap` 96px 高）改成**单行折叠**：默认 44px 高、一行提示语；
  聚焦后展开到 120px 并露出材料级/板块 chips。少一层常驻面积，首屏能多放半屏内容。
- **列表**：默认 **2 列编辑卡片**（≤1100 时 2 列，>1100 仍 2 列但列宽更大；手机 1 列）。
  卡片去掉阴影与外边框，改为"白面 + 发丝线"，标题 15/24 两行截断，摘要 13.5 三行截断，
  底部 meta 一行（来源 · 材料级 · 笔记数）。悬停只变底色 2%，不位移。
- **列表/卡片密度切换**：右上角一个图标按钮，紧凑模式行高 64、单列，适合批量扫读。存 `localStorage`。
- **标签**：从一整排 chips 改成"前 6 个 + 更多 ▾"，避免标签多时把首屏顶下去。
- **右栏 inspector（≥1280 才出现）**：点卡片右侧出现 340px 预览（标题、摘要、AI 摘要、三个动作），
  不跳页就能判断"要不要展开"。这是"工作台感"的关键增量。

### 4.3 收存详情

```
← 返回        [T0] 权威 · 国家统计局 · 2021-05-11            ⋯
第七次人口普查数据公报（第三号）
─────────────────────────────────────────────  ────────────────────
 目录            正文（68ch）                    批注 / 笔记 / AI
 · 摘要          首段下沉，行高 1.75               ┌──────────────┐
 · AI 摘要       引用块左边 2px 铜线               │ 划重点 3      │
 · 原文          ─────────────                   │ 笔记 2        │
 · 我的批注      正文配图宽 100%，图注 12px         │ ＋ 写一条     │
 · 相关                                                 └──────────────┘
```

- **三栏固定**：左 220（本条目录，sticky）、中 `min(68ch, 1fr)`、右 340（批注/笔记/AI 分 tab）。
- 顶部标题区 sticky 48px：滚动后只留小标题 + 操作，原 `.clip-head` 的大标题在正文上方一次性出现。
- 阅读进度：顶部 2px 铜线（替代现有浮动进度），细、安静、不遮挡。
- 工具条（`.clip-tools`）从"一排按钮"改成"右侧 `⋯` 菜单 + 两个高频动作"，减少视觉噪音。
- 正文里 `.prose` 的行高从 1.8 提到 1.75 但字号 15px，观感更"书"。

### 4.4 阅读中心

**书架总览**

```

──────────────────────────────────────────────────────────────────────

│      │ │      │ │      │ │      │ │ 新建 │

 书名     书名     书名     书名

```

- 书架从"卡片列表"改成**书脊/封面网格**（`repeat(auto-fill, minmax(132px,1fr))`），
  封面 3:4，标题两行，进度用 2px 细线而不是圆环（圆环在列表里太抢眼）。
- 顶部加"继续阅读"横向大卡：封面 + 书名 + 上次读到第几章 + 「继续」按钮。这是阅读产品的第一入口。
- 筛选（书架/状态/格式）从一排 chips 移到语境栏，主区只留内容。

**阅读器（保留三栏，重新分配宽度）**

- 左右栏可收起（`[` / `]`），收起后正文真正居中——现在的三栏在 1440 下正文偏左。
- 顶栏在滚动 200px 后自动隐藏，鼠标移到顶部再出现（沉浸阅读必需）。
- 字号/行距面板改成右下角浮层（14px 圆角），不再占一栏。

### 4.5 圣经

```
┌ 读经台 ────────────────────────────── 和合本 · 约翰福音 ▾ ┐
├──────────┬──────────────────────────────────┬─────────────┤
│ 书卷 240 │  约翰福音 第五章                  │ 标注 340    │
│ 旧约 ▾   │  ─────────────────────           │ 划重点 8    │
│ 新约 ▾   │  1 事后，到了犹太人的一个节期…    │ 灵修笔记 3  │
│          │  2 在耶路撒冷，靠近羊门有一个池子…│             │
└──────────┴──────────────────────────────────┴─────────────┘
```

- **去掉照片背景**（`bible-bg.jpg`）。它是三个板块里最"不高级"的一处：照片的色温与纸底冲突，
  且直接影响正文对比度。改用"纸底 + 极浅纸纹（CSS 4% 噪声或纯色）"。
- 经文体：衬线 17/32（比正文大一号，读经需要更松的行距），节号用 11px 上标铜色。
- 五色高亮：统一为"底色 12% + 左边 2px 同色线"，取消现在的实心底条。
- 目录：书卷折叠树（旧约/新约），当前章加铜点；章号网格 8 列，触控 36px。

### 4.6 工具页（问 / 洞察 / 检索 / 判断 / 回顾 / 设置）

统一一种版式：**页头（标题 + 一句解释）→ 输入区 → 结果区**，不再每页各写一套。

```

──────────────────────────────────────────────────────────────────────
┌────────────────────────────────────────────────────────────────────┐
│ 问点什么……                                              ⌘↵ 发送     │
└────────────────────────────────────────────────────────────────────┘
引用范围：全部收存 ▾   材料级：材料 ▾

回答
──────────────────────────────────────────────────────────────────────
正文（68ch）…  [1] 第七次人口普查数据公报
```

## 七、不影响功能的实现约束（硬要求）

**总原则：只加一层样式，不动结构、不动类名、不动事件。**

1. **新增一个文件** `static/theme-v2.css`，在 `index.html` 里作为最后一个 `<link>` 引入。
   旧 CSS 一行不改，出问题删掉这一行即回到现状。
2. **不新增/不重命名任何 class 与 id**。所有调整通过现有选择器完成：
   `.shell` `.side` `.brand` `.nav` `.nav-item` `.sect-switch` `.side-foot` `.main` `.head`
   `.panel` `.stat-grid` `.cap` `.filters` `.chip` `.g-head/.g-tabs` `.clip-grid` `.clip-card`
   `.claim-row` `.detail-grid` `.tabs` `.toast` `.fab`，阅读区 `.rc-*`，圣经 `.bl-*`。
3. **不新增 DOM**。轨道栏、统计条、右栏 inspector 全部用 CSS 在现有节点上重排：
   - 轨道 = `.side` 的 `grid-template-columns` 重排 + `.sect-switch` 竖排 + `position: sticky`；
   - 语境栏 = `#nav-vault` / `#nav-reading` / `#nav-bible` 作为第二列；
   - 工具条 = `.main > .head` 用 `position: sticky` 贴顶（不插新节点）。
   - 需要"多一个按钮"的地方（如密度切换、inspector）**本期不做**，避免碰 JS。
4. **样式权重**：全部用 `:where()` 包裹，特异性为 0，天然被现有规则覆盖；
   需要覆盖时必须 `!important` 的地方集中在文件末尾的"覆盖区"，并逐条注释原因。
5. **变量优先**：`theme-v2.css` 只重定义 `:root` 变量（颜色/字号/间距/圆角/动效），
   组件规则尽量少的重写；现有 `style.css` 里的组件会自动跟着变。
6. **主题切换不改**：`data-theme="dark"` 机制保留，只换数值；`#theme-toggle` 文案与行为不变。
7. **路由与状态不改**：`data-route`、`href="#/..."`、`localStorage` 键（`gl_resurface_hidden` 等）全部沿用。
8. **响应式断点统一**为 860 / 720 / 560 三档，旧的三套断点用 `@media` 覆盖，不改原文件。
9. **可回退**：`<body data-skin="v2">` 由一行内联脚本设置（读 `localStorage.gl_skin`，默认 v2）；
   删掉即回 v1。这是唯一允许的 JS 改动，且不触碰任何业务函数。
10. **验收用真实 DOM**：所有改动在浏览器 DevTools 里逐页核对，禁止"看起来差不多"。
