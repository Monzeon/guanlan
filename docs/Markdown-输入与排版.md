# 输入框自动识别 Markdown · 手写内容规范排版

> 改动文件：`static/app.js`、`static/reading.js`、`static/extra.css`、`README.md`。
> 逐行差分见 [`Markdown-输入与排版.patch`](Markdown-输入与排版.patch)。

## 一、问题

「我的话」面板里存着一段带 Markdown 的笔记，显示的却是记号本身：

```
提问：福山为什么说"人之所以为人…"

回答：[R]

他论证了，但论的不是"证明"，是"重构"。下面把这条链子拆开看。

---

# 福山的"承认"论：论证的机构与裂缝

## 一、这句话从哪儿来
柏拉图在《理想国》卷四（435-441）把灵魂切成三份：**logistikon**（理性）、…
```

`#`、`##`、`**`、`---` 原样露在正文里，层级读不出来，重点也看不出来。同一个毛病在
「我的判断」「随手记」「批注」「AI 简介」上都存在——它们都走 `esc(text) + <br>`，
只当纯文本处理。

## 二、做法

一套共用能力放在 `app.js`，阅读中心通过 `window.GL` 复用：

| 函数 | 用途 |
|---|---|
| `mdBody(text, cls)` | 显示用：`<div class="md-body">` + `markdownHtml()`，标题/列表/引用/分隔线/代码块/表格都按版式落下 |
| `mdPlain(text, limit)` | 摘要用：把记号摘掉，只留干净句子（列表卡片的两行预览） |
| `hasMarkdown(text)` | 判断有没有记号：没有就不额外渲染，纯文本照旧 |
| `bindMdPreview(root)` | 编辑时边写边看：给 `textarea[data-md-preview]` 挂一块实时预览 |

**渲染位**（存下来之后怎么显示）：

| 位置 | 字段 |
|---|---|
| 我的话（详情页引言块） | `clips.excerpt` |
| 我的判断 | `verdicts.text` |
| 随手记 | `clip_notes.text` |
| 批注卡（页边批注） | `clip_annotations.note` |
| AI 简介 / AI 产出 | `clips.summary`、`outputs.content` |

**预览位**（正在写的时候）：收存框、判断、随手记、批注、简介改写、AI 产出改写；
阅读中心的笔记与批注弹窗也走同一套。

两个细节：

- **纯文本不动**：`hasMarkdown()` 只为真写了记号的输入长出预览；显示侧 `markdownHtml()`
  把单行包成 `<p>`、换行保留成 `<br>`，和原来的 `esc + <br>` 视觉一致。
- **中文写法也认**：`#标题`（`#` 后直接跟汉字，没有空格）按一级标题处理；`#1 号` 仍是正文
  ——判据是 `#` 后面那一格是不是非 ASCII 字符。

卡片摘要用 `mdPlain()` 去掉记号，避免标题行带着 `##` 出现在两行预览里。标题取第一行时
同样先摘记号，`# 收存一条` 存下来标题是「收存一条」，不是「# 收存一条」。

## 三、效果

同一段内容，改前 / 改后：

```
改前  # 福山的"承认"论：论证的机构与裂缝
      一、这句话从哪儿来
      柏拉图在《理想国》卷四把灵魂切成三份：**logistikon**（理性）、`epithmetikon`（欲望）

改后  福山的"承认"论：论证的机构与裂缝      ← 衬线大标题
      一、这句话从哪儿来                    ← 二级标题
      柏拉图在《理想国》卷四把灵魂切成三份：logistikon（理性）、epithmetikon（欲望）
                                            ← 粗体加粗、行内代码带底色
```

编辑时的预览（收存框为例）：

```
┌────────────────────────────────────────────┐
│ # 收存一条测试                              │  ← 输入框：原样保留记号
│ 下面是一段 **重点** 和 `code`：              │
└────────────────────────────────────────────┘
 预览
 收存一条测试                                  ← 衬线标题
 下面是一段 重点 和 code：                     ← 粗体 / 代码
   • 第一点
   • 第二点
```

## 四、边界

- **正文不渲染 Markdown**：阅读器的正文带字符坐标（批注锚点、进度、检索都靠它），
  渲染成 HTML 会把坐标体系打散。正文里若出现 `#`，那是原文的一部分。
- **安全**：`mdInline()` 先 `esc()` 再上记号，链接只放行 `http(s)`，不引入外部库、不联网。
- **性能**：预览按 `input` 事件重渲染，几 KB 的文本是毫秒级；超过 340px 高自动滚动。
- **不改数据**：库里存的仍是原始 Markdown 文本，导出、检索、AI 读到的都是原文。

## 五、生效与回滚

- 纯前端改动：刷新浏览器（Ctrl+F5）即可，不必重启服务；老条目不用重存。
- 回滚：`python tools/rollback_md_render.py --apply`（先 `--dry-run` 预览），
  三个静态文件退回 `*.bak-20261109-md`，README 那条一起删掉。
