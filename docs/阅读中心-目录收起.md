# 阅读中心 · 目录能收起来了

> 变更记录，对应文件：`static/reading.js`、`static/reading.css`、`README.md`。
> 逐行差分见 [`阅读中心-目录收起.patch`](阅读中心-目录收起.patch)，验证截图在 [`shots-toc-fold/`](shots-toc-fold/)。

## 一、问题

打开一本书，左边目录是死钉在网格里的一列：21 章铺下来占满整栏，正文永远少 244px；顶栏的「☰」只在窄屏有用，宽屏点了没反应；右边标注栏同理。
目录这个动作是「临时看一眼」，看一眼就得一直付 244px 的代价——所以这次让它能收。

## 二、改完是什么样

| 场景 | 操作 | 结果 |
|---|---|---|
| 宽屏（>900px） | 栏头「«」/ 顶栏「☰」/ 按 `[` | 左栏收到 0，正文 656 → 900px，220ms 过渡；左边缘留一条竖签「目录」 |
| 宽屏 | 点左边缘竖签 / 再按 `[` | 目录原样展开，宽度、选中章、滚动位置都还在 |
| 宽屏 | 右栏「»」/ `▤` / 按 `]` | 标注栏同样收起，右边缘留竖签「标注」 |
| 窄屏（≤900px） | 「☰」/「▤」 | 抽屉 + 半透明遮罩；`Esc`、点遮罩、点章节/书签后自动收 |
| 任意宽度 | —— | 收起状态写进 `localStorage.gl_reading_prefs.leftOpen / rightOpen`，下次打开还是原样 |
| 任意宽度 | 折列/回开 | 正文不跳行：把「视线所在的那一段」按相对位置钉回去 |

另外两处顺手的小修：

- 目录长了，当前章可能滚出面板视野 —— 每次渲染把选中项 `scrollIntoView({block:"nearest"})` 拉回可见。
- 目录条目 `title` 补上「全名 · 约 N 百字」，被 244px 截断的标题可以悬停看全。

## 三、实现要点

### `static/reading.js`

| # | 位置 | 改动 |
|---|---|---|
| 1 | `P` 偏好 | 新增 `leftOpen` / `rightOpen`，跟字号、纸张一起存本机 |
| 2 | `narrow()` | `matchMedia("(max-width: 900px)")`，宽窄两套开合语义的唯一判据 |
| 3 | `renderBookShell` | reader 根节点按偏好挂 `no-left` / `no-right`；新增两条边缘竖签 `#rc-rail-left/right` 与遮罩 `#rc-scrim`；顶栏按钮补 `aria-controls` / `aria-expanded` |
| 4 | `setSide / toggleSide / applySide` | 宽屏改网格列 + 存偏好；窄屏改 `show-left/show-right` 抽屉；统一维护 `inert`、`aria-hidden`、遮罩显隐 |
| 5 | `renderLeft` / `renderRight` | 标签行包进 `.rc-panel-head`，右侧固定一枚「«」/「»」收起按钮 |
| 6 | `bindBook` | 竖签、遮罩、跨 900px 断点的状态归位；`[` / `]` 快捷键；`Esc` 收抽屉 |
| 7 | `bookAnchor / restoreAnchor` | 收放前后按段落 + 像素偏移钉住视线，等 300ms 过渡结束再落位 |
| 8 | `topIn()` | 新增几何工具：用 `getBoundingClientRect()` 算元素相对滚动容器的距离，替换原来的 `p.offsetTop - 90`（续读定位、跳转定位两处） |

第 8 条不是顺手改：`.rc-reader` 为了放绝对定位的竖签加了 `position: relative`，它就成了正文段落的 `offsetParent`，`offsetTop` 会整体多出顶栏那一截（实测 185px）。继续用 `offsetTop` 会让「续读」和「跳转」落错行，所以一并换成 rect 计算——顺带把原来「距顶 90px」实际只有 34px 的偏差也修了。

### `static/reading.css`

- `.rc-rgrid` 的三列改成 `--rc-lw / --rc-rw` 变量，`no-left` / `no-right` 把对应列压到 0，过渡 220ms；≤1180px 只改变量，折列规则自动跟随。
- 折列/抽屉的所有规则都关在 `@media (min-width: 901px)` 里，窄屏只走原来的抽屉那套，互不串味。
- 新增 `.rc-panel-head`（标签行 + 收起键同一行，标签可横向滚动）、`.rc-fold`、`.rc-rail`（竖排文字边签）、`.rc-scrim`。
- 配色沿用原有变量（`--panel-2` / `--line` / `--dim` / `--accent`），没引入新色。

### `README.md`

「阅读中心」章节补一行说明：两栏可收、快捷键、状态记忆。

## 五、回滚

```bash
python tools/rollback_toc_fold.py --dry-run     # 预览
python tools/rollback_toc_fold.py --apply       # 还原 reading.js / reading.css / README 那一行
python launch.py --stop && python launch.py     # 重启生效
```

脚本按备份文件还原、按整行精确删 README 的新增行；若文件已被后续手改（特征串对不上）会跳过并提示，不会覆盖新工作。`--keep-docs` 可保留本次的验证脚本与截图。
