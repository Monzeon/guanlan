# 观澜 · 事件专题（桌面端）

实施日期：2026-11-18

## 范围

- 桌面侧栏新增「事件」，四入口为 2×2；阅读中心在入口中保留全称。
- 事件列表：跟踪中 / 暂停 / 归档 / 全部、搜索、最新进展与计数。
- 事件详情：实际发生时间排序的进展、资料关联、当前认识、待解问题、归档总结、Markdown 导出。
- 收存详情：保持纯收存，不显示任何事件内容（2026-11-25 调整，见文末）。
- 不修改移动端文件和底部导航，不做自动全网监控或 AI 功能。

## 数据保护

`event_topics`、`event_updates`、`event_clip_links` 是独立追加式表。旧 `events` 时间锚点不迁移、不覆盖；`clips` 仍是资料唯一事实源。首次调用事件接口才幂等建表，避免启动时为未使用的模块增加工作。

删除事件只删除其进展和关联，不删除原收存；删除原收存只清关联。事务沿用 `server._post_route` 统一提交与回滚。JSON 导出新增 `event_topics` 节点，快照同步继续整库传输。

## 性能

- 列表固定一次聚合查询 + 一次计数查询，不随事件数增加请求或 SQL 次数。
- 资料搜索只读取标题等轻字段，不读取正文、图片和附件。
- 新表按状态、事件 ID、收存 ID 建索引；列表最多返回 500 个事件，资料搜索最多 20 条。
- 圣经侧栏状态只在进入圣经板块时加载，离开不再产生多余请求。
